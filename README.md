## About this site

A single static page (`index.html`) with no build step and no dependencies beyond Google Fonts.

- **Bilingual:** an EN / 한국어 toggle switches all content and download links. It remembers your choice and defaults to your browser's language.
- **Light and dark themes**, following the system setting
- **Scroll animations**, which are turned off automatically for users who prefer reduced motion
- **Responsive** layout for mobile, tablet, and desktop
- Hosted on **GitHub Pages**

```
├── index.html       # the whole site (HTML + CSS + JS)
├── resume.pdf       # 이력서 (Korean)
├── resume_en.pdf    # Résumé (English)
├── career.pdf       # 경력기술서 (Korean)
├── career_en.pdf    # Career details (English)
└── README.md
```

To preview locally, open `index.html` in any browser.
